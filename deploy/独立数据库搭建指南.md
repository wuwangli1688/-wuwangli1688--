# 独立数据库搭建指南

## 方案一：Supabase（推荐，免费额度够用）

Supabase 本身就是 PostgreSQL，自带管理后台，开箱即用。

### 操作步骤

#### 1. 注册 Supabase

打开 https://supabase.com → 点击 **Start your project** → 用 GitHub 登录

#### 2. 创建项目

| 配置项 | 填写 |
|--------|------|
| **Name** | 随便填，如 `ledger-db` |
| **Database Password** | 点击生成密码，**复制保存好** |
| **Region** | 选 **Singapore**（离国内最近） |
| **Pricing Plan** | **Free**（免费额度：500MB 数据库，5万月活用户，够用） |

点击 **Create new project**，等 2-3 分钟创建完成。

#### 3. 执行建表

创建完成后，左侧菜单进入 **SQL Editor** → 点击 **New query** → 把 `deploy/schema.sql` 的完整内容粘贴进去 → 点击 **Run**。

执行成功后，左侧 **Table Editor** 里能看到所有表。

#### 4. 获取连接信息

左侧菜单 → **Project Settings** → **Database** → 找到：

- **Project URL**（即 `SUPABASE_URL`）
- **anon public** 密钥（即 `SUPABASE_ANON_KEY`）

```
SUPABASE_URL = https://xxxxxxx.supabase.co
SUPABASE_ANON_KEY = eyJhbGciOiJ...
```

#### 5. 配置到服务器

SSH 登录服务器，更新环境变量：

```bash
cd /app/ledger/deploy

# 编辑 PM2 配置文件
nano ecosystem.config.js
```

找到 `env` 部分，把 `COZE_SUPABASE_URL` 和 `COZE_SUPABASE_ANON_KEY` 替换成你自己的值：

```javascript
env: {
  COZE_SUPABASE_URL: 'https://你的项目.supabase.co',
  COZE_SUPABASE_ANON_KEY: '你的anon-key',
  JWT_SECRET: '638b39c8f0a5b139286dfc739969cd6c1774e3436361156e59f310b9319d2625',
  PORT: 9091
}
```

然后重启：

```bash
pm2 delete ledger-api
pm2 start /app/ledger/deploy/ecosystem.config.js
pm2 save --force
```

#### 6. 验证

```bash
curl https://wuwanli.online/api/supabase-config
```

返回 `{"url":"https://你的项目.supabase.co",...}` 即表示成功。

## 方案二：腾讯云 PostgreSQL

如果你想把数据库也放在腾讯云统一管理：

### 1. 购买数据库

腾讯云控制台 → **云数据库 PostgreSQL** → **新建实例**：

| 配置项 | 推荐值 |
|--------|--------|
| 计费模式 | 按量计费（先用后付） |
| 地域 | 和服务器同区（如上海） |
| 规格 | 1核1GB（起步够用） |
| 存储 | 20GB SSD |
| 版本 | PostgreSQL 15+ |

### 2. 创建数据库和用户

购买完成后，进入控制台：

- 点击实例名进入详情
- 找到 **数据库管理** → **新建数据库**，名称 `ledger`
- 找到 **账号管理** → **创建账号**，设置用户名密码

### 3. 设置白名单

在实例详情 → **安全组** → 添加规则，放行服务器 IP `118.195.198.69` 的访问。

### 4. 连接到数据库执行建表

在服务器上执行：

```bash
# 安装 PostgreSQL 客户端
yum install -y postgresql

# 连接到数据库
psql -h 你的数据库地址 -U 用户名 -d ledger

# 输入密码后，执行建表
\i /app/ledger/deploy/schema.sql

# 退出
\q
```

### 5. 配置环境变量

和方案一第5步一样，把 `ecosystem.config.js` 中的 `COZE_SUPABASE_URL` 和 `COZE_SUPABASE_ANON_KEY` 换成你的 PostgreSQL 连接信息。但注意，代码里用的是 Supabase 客户端，如果换成普通 PostgreSQL，需要额外修改代码。

---

## ⚠️ 重要提醒

**方案一（Supabase）最省事**，因为：
1. 代码已经用 Supabase 客户端写的，不需要改代码
2. 免费额度足够个人使用
3. 自带管理后台，可以看到数据和表结构

**方案二（腾讯云 PG）** 需要额外改代码，把 Supabase 客户端换成普通 `pg` 驱动，不推荐自己折腾。

**建议先用方案一**，把免费 Supabase 用起来，后续有需要再迁移。
